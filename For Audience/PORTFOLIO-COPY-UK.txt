НАЗВА ПРОЄКТУ
RalseiFlow — замовлення, запаси й бізнес в одному місці.

КОРОТКИЙ ОПИС
Незалежний повностековий застосунок для керування клієнтами, товарами, замовленнями та запасами в одному робочому просторі. RalseiFlow поєднує рух замовлень з обліком запасів і зведеннями продажів за вибраний період.

ПОВНИЙ ОПИС ПРОЄКТУ
RalseiFlow — незалежний повностековий застосунок для керування даними клієнтів, товарами, замовленнями та запасами в одному робочому просторі. Він поєднує активність замовлень, доступні залишки та звіти про продажі, щоб щоденні операції було зручно переглядати в одному контексті.

Ціни в замовленнях розраховуються на сервері на основі збережених даних товарів. Під час створення замовлення запас резервується, а зміни статусу зберігаються в історії. Працівники можуть реєструвати надходження та переглядати рух товарів; адміністратори й працівники мають доступ відповідно до своїх ролей. Аналітика підсумовує замовлення та продажі за вибрані дати.

Інтерфейс створено на React і TypeScript, серверну частину — на ASP.NET Core, а дані зберігаються в PostgreSQL. Для локального запуску передбачено Docker Compose. Це перевірений портфоліо-проєкт із локальними демонстраційними записами, а не підтверджене комерційне впровадження чи заява про бізнес-результати.

ОСНОВНІ ФУНКЦІЇ
- Керування клієнтами й товарами.
- Створення замовлень із розрахунком ціни на сервері.
- Життєвий цикл замовлення та історія статусів.
- Резервування запасу, його повернення після скасування та рух під час виконання замовлення.
- Реєстрація надходжень і журнал складських операцій.
- Рольовий доступ для Admin і Employee.
- Аналітика продажів із фільтром за датами.
- REST API на базі PostgreSQL і локальний запуск через Docker Compose.

ТЕХНОЛОГІЇ
C#, .NET 10, ASP.NET Core, Entity Framework Core, PostgreSQL, React, TypeScript, Vite, JWT-аутентифікація, рольова авторизація, Docker Compose, FluentValidation, Serilog, Swagger, xUnit.

МІЙ ВНЕСОК / ПІДХІД ДО РОЗРОБКИ
Незалежний портфоліо-проєкт із використанням AI-підтримки під час реалізації. Робота виконувалася ітеративно: інтерфейс, інтеграція API та бази даних, перевірка поведінки й документація. Результат перевірявся збірками, автоматизованими тестами та локальними перевірками; це не означає, що кожен рядок коду написано без допомоги.

СТАТУС ПРОЄКТУ
Завершений портфоліо-проєкт. Release-збірки й автоматизовані тести проходять; конфігурацію Docker Compose та доступність локального API перевірено. Це локальний демонстраційний проєкт, а не підтверджене комерційне впровадження.
